## 제작 의도
처음에 이 프로젝트를 시작할 때는 마케팅 에이전트를 한번도 만들어본 경험이 없어
어떻게 만들어야 하나 고민이 많았습니다. 그래서 최대한 사용하기 쉽게 화면을 3분할했고,
주어진 프로세스에 맞게 쓸 수 있도록 안내하고자 앞에 숫자도 덧붙였습니다.

맨 처음에 보이는 영상 불러오기 및 목록을 구현하기 위해
상태를 전체 / 작업 대기 / 댓글 완료 이렇게 3개로 구분했습니다.
그리고 특정 키워드를 입력하면 영상을 찾을 수 있는데,
가이드에 명시된 키워드는 연애라서 일단 그 키워드만 지정해서 검색할 수 있게 했습니다.

일반 영상을 찾으려면 검색 창에 키워드를 입력하면 되고,
뜨기 직전 영상 (조회수 1,000 ~ 5,000회 / 시간당 150회 이상) 을 찾으려면
필터를 체크하고 검색하면 됩니다. 이렇게 해야 사용이 좀 더 간편하기 때문이었습니다.

검색을 하고 나면 2번째 칸에 선택된 영상과 데이터 추출 상태가 뜹니다.
추출된 스크립트와 인기 댓글 상위 5~10개를 보여줘서
댓글을 작성할 때 AI가 참고할 수 있도록 했습니다.
그리고 영상 속 고민을 한 줄로 요약하여
어떤 영상인지 쉽게 파악할 수 있게 했습니다.

그 아래에는 AI 댓글 초안이 있는데
처음에 영상 선택을 했다면 자동으로 초안이 생성되지만,
만약 초안이 기준에 못 미치거나 마음에 안 들 경우
초안 다시 생성 버튼을 누르면 새로운 내용으로 변경됩니다.

그리고 실제 달린 댓글의 문투를 분석하여 다양한 유형별로
자연스럽게 초안을 작성할 수 있게 했습니다.
추천된 내용을 클릭만 하면 바로 사용할 수 있고,
직접 수정도 가능합니다.

3번째 창에서는 가이드에 명시된 대로
크롬 프로필 3개를 각각 연결하여 세팅할 수 있는데요.
설정하고 싶은 프로필을 선택한 뒤
우측의 프로필 열기 (로그인 세팅용)을 누르면
구글 계정에 바로 로그인 가능합니다.

설정된 프로필은 구글 크롬 경로에 저장되는 게 아닌
프로그램 폴더에 있는 chrome_profiles 폴더에서
각 프로필별로 폴더를 만들어 그 안에 보관합니다.
그래야 관리하기도 쉽고 보안상 문제가 없기 때문입니다.

아무튼 프로필을 선택하고 [프로필명] 크롬 프로필로 댓글 달기 실행을 누르면
프로그램이 브라우저를 직접 조작하여 댓글을 타이핑하고,
직접 등록까지 해줍니다.

다만 도배로 인해 계정 정지되는 일이 발생하지 않도록
영상당 댓글 1개씩, 하루에 최대 10개씩만 게시할 수 있게 했습니다.
아래에는 실시간으로 브라우저 자동화가 어떻게 진행되는지도 알 수 있습니다.

실시간 실행 로그에는 프로그램을 실행하면서 발생하는 상황에 대해 알려주는데요.
만약 에러가 발생할 경우 그 시점을 캡처한 뒤
로그에 표시해줌으로써 어떤 오류인지 알 수 있습니다.

마지막으로 작업 히스토리에는 지금까지 진행한 작업 내용들을
시간순으로 볼 수 있습니다.
히스토리가 쌓이면 쌓일수록 프로그램의 성능에 영향을 미치니
전체 비우기 기능을 통해 수시로 정리하게끔 구현했습니다.

읽어주셔서 감사합니다.
